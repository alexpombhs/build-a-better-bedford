# Build a Better Bedford

Unofficial student-led civil engineering club website.

## Tech stack

- React
- TypeScript
- Vite
- GitHub Pages

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The Vite base path is configured for the GitHub Pages project URL:

`/build-a-better-bedford/`

> This is an independent student-run project and not an official Town of Bedford website.
